# Skills — source log

These skills are written **specifically for the Manzil demo** (not vendored or
copied from another project). `AGENTS.md` routers decide when each is loaded via
the skill tool.

## Always-ON (via `opencode.json` → `instructions`)

- `design-system` — token discipline (see `docs/DESIGN.md`)
- `frontend-design-direction` — anti-slop direction and restraint
- `verification-loop` — the mandatory pre-done loop

## Manzil-specific

- `manzil-blueprint` — enforce `docs/BLUEPRINT.md` as the source of truth
- `manzil-story-engine` — the interactive flow: schema, engine, editing steps
- `manzil-content` — content-as-data, zod, card workflow
- `manzil-map` — the journey/route line and waypoint visuals

## Craft / design

`make-interfaces-feel-better`, `motion-foundations`, `motion-patterns`,
`motion-advanced`

## Frontend

`react-patterns`, `react-performance`, `nextjs-turbopack`, `frontend-a11y`,
`accessibility`, `error-handling`, `security-review`

## Process

`verification-loop`, `browser-qa`, `git-workflow`, `production-audit`,
`deployment-patterns`

## Customizing

Edit these freely as the project evolves. If a skill changes a standing rule,
reflect it in `AGENTS.md`/`docs/DESIGN.md` too — skills are guidance, the docs
are the contract.
