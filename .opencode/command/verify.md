description: Run the verification loop on the current work
---

Load the `verification-loop` skill and run it against the current state of the
project. Follow the reporting format exactly:

- Verified — what you ran and the result
- Measured — numbers against any budget
- Not verified — anything you could not check, and why
- Risks or follow-ups

Do not skip steps and do not claim anything you did not run. Start with
`npm run check` and paste the tail of the real output.
